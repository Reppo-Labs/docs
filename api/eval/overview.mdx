The **Evaluation API** lets your agent submit its work for a verdict and read the result back over HTTP. It is the same service that powers the console at [eval.reppo.xyz](https://eval.reppo.xyz). For how verdicts are produced, see [What is the Reppo Evaluation API?](/concepts/evaluation-api).

<Tip>
  Building with a coding agent? Point it at [eval.reppo.xyz/agents.md](https://eval.reppo.xyz/agents.md). It's a plain-Markdown version of this reference meant to go straight into an agent's context. It also covers paying with x402 instead of an API key, running an evaluation in a loop, and connecting over MCP.
</Tip>

## Base URL

```
https://eval.reppo.xyz/api/v1
```

All API key endpoints in this section live under `/agents/evals`.

| Endpoint | Purpose |
|---|---|
| `POST /agents/evals` | [Submit an evaluation](/api/eval/evaluations#submit-an-evaluation) |
| `GET /agents/evals/{id}` | [Read an evaluation result](/api/eval/evaluations#read-an-evaluation-result) |
| `POST /agents/evals/attachments` | [Request an attachment upload URL](/api/eval/evaluations#submit-with-an-attachment) |

## Authentication

Every request needs an API key in the `Authorization` header:

```
Authorization: Bearer YOUR_API_KEY
```

API keys belong to a signed-in account, so an agent can't create its own. To get one:

<Steps>
  <Step title="Sign in">
    Sign in at [eval.reppo.xyz](https://eval.reppo.xyz).
  </Step>
  <Step title="Generate a key">
    Open **API Key** in the sidebar and click **Generate API key**.
  </Step>
  <Step title="Store it as a secret">
    Copy the key immediately. It's shown only once. Pass it to your agent as an environment variable.
  </Step>
</Steps>

## Credits

| Item | Amount |
|---|---|
| Sign-up bonus | 22,000 credits, one time |
| Text-only evaluation | 440 credits (50 evaluations from the sign-up bonus alone) |
| Evaluation with an image or PDF attached | 1,000 credits |

Credits are charged only once the evaluation is `COMPLETED`. A `FAILED` evaluation costs nothing. There is no API endpoint for buying account credits, so a person has to buy more on the [Billing](https://eval.reppo.xyz/billing) page.

You can have several evaluations in flight at once. Each one reserves its price against your balance until it finishes, so submitting several needs enough credits to cover all of them.

## Limits

| Limit | Value |
|---|---|
| `taskType` | Required: `claim`, `response`, or `action` |
| `input` | Required, non-empty, up to 50 KB |
| Attachments | Up to 1 per evaluation, 1.25 MB: PNG, JPEG, WebP, or PDF |

## Evaluation statuses

| Status | Meaning |
|---|---|
| `QUEUED` | Accepted and waiting to be scored. No result yet. |
| `PROCESSING` | Being scored by the panel of evaluators. |
| `COMPLETED` | Scored. `result` holds the verdict and credits were charged. |
| `FAILED` | The evaluation could not be completed. Nothing was charged. Submit it again. |

## Errors

| Code | Meaning |
|---|---|
| `400` | The request body failed validation, or an attachment is missing or too large |
| `401` | Missing or invalid API key |
| `402` | Not enough credits: 440 for a text-only evaluation, 1,000 with an attachment |
| `404` | No evaluation with that `id`, or it belongs to a different account |
| `500` | Unexpected server error |
| `502` | The evaluation couldn't be queued. It's returned as `FAILED` and not charged, so try again. |
